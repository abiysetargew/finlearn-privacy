# FinLearn — Privacy Policy

This repository hosts the public privacy policy for **FinLearn: Forex & Markets**
(Google Play package: com.finlearn.ethiopia).

Live URL: https://abiysetargew.github.io/finlearn-privacy/

The app itself is private and its source is not published here. This repo
contains only the policy page that Google Play requires to be publicly
reachable.

The source of truth for this page lives in the private app repository at
docs/pages/index.html.
